# 🍲 Bayti Byte – Homemade Food & Cloud Kitchen App

**Bayti Byte** is a mobile food ordering application that connects customers with home cooks and cloud kitchens, making it easy to discover, order, and enjoy freshly prepared homemade meals.

The application offers a seamless and user-friendly experience, allowing customers to explore different cuisines, discover local home cooks and cloud kitchens, manage their orders, and track deliveries.

Built using **React Native, Expo SDK 58, and NativeWind**, Bayti Byte is designed to provide a modern and intuitive mobile experience.

## 🚀 Getting Started

### Prerequisites

Before running the application, make sure you have the following tools installed:

- **Node.js and npm** – For managing dependencies and running the development server.
- **Git** – For cloning and managing the repository.
- **Visual Studio Code** – Recommended code editor.
- **Expo Go** – For testing the application on a physical mobile device.
- **Expo SDK 58** – The SDK version used for development and testing.

### 1. Clone the Repository

```bash
https://github.com/shahdaayman/BaytiBite-Mobile-Development-Phase-1.git
```

### 2. Navigate to the Project Directory

```bash
cd Bayti-Byte
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npx expo start
```

This command starts the Expo development server and displays a QR code for launching the application.



## 📱 Testing & Compatibility

Bayti Byte has been **tested on a physical iOS device using Expo Go with Expo SDK 58**.
